# Публикация прототипа

Приложение — один Docker-образ (`Dockerfile` в корне): внутри собранный frontend и FastAPI-сервер на порту **8000**.
База — SQLite в постоянном томе **`/data`** (или PostgreSQL через `DATABASE_URL`). При первом старте БД заполняется
демо-данными автоматически. Требование ТЗ: сайт открывается из России без VPN и работает до объявления итогов (28 ноября).

## Вариант 1 (рекомендуемый): Amvera Cloud — российский PaaS, деплой через `git push`
Amvera — российская платформа с деплоем по `git push` или через загрузку файлов в интерфейсе; есть постоянное
хранилище `/data`, бесплатный домен с HTTPS, оплата российской картой и стартовый баланс для теста.

1. Зарегистрируйтесь на amvera.ru → «Создать проект» → тип **Приложение**, окружение **Docker**.
2. В корне репозитория уже лежит `amvera.yml` (Dockerfile, `containerPort: 8000`, `persistenceMount: /data`).
3. Загрузите код: либо подключите GitHub-репозиторий в настройках проекта, либо
   ```bash
   git remote add amvera https://git.amvera.ru/<пользователь>/<проект>
   git push amvera main:master
   ```
4. В разделе «Переменные» задайте (по желанию) `UNIVERSITY_NAME`; остальное уже задано в образе
   (`APP_ENV=production`, `COOKIE_SECURE=true`, `DATABASE_URL=sqlite:////data/deanate.db`).
5. В настройках проекта подключите бесплатный домен платформы — получите публичный HTTPS-адрес.
6. Дождитесь сборки (3–6 минут) и проверьте по чек-листу ниже.

## Вариант 2: VPS в РФ (Timeweb Cloud, Selectel, Yandex Cloud и т.п.) + свой домен
```bash
# на сервере с Docker; A-запись домена указывает на IP сервера
git clone <репозиторий> deanate && cd deanate
DOMAIN=deanate.example.ru docker compose -f deploy/docker-compose.prod.yml up -d --build
```
Caddy автоматически получит сертификат Let's Encrypt. Без домена: `docker compose up -d --build` → `http://<IP>:8000`
(в этом случае в `docker-compose.yml` уже стоит `COOKIE_SECURE=false`; для конкурса лучше HTTPS).

## Вариант 3: любой хостинг Docker-контейнеров
Образ: `docker build -t deanate .`; порт 8000; смонтируйте постоянный том в `/data` (иначе данные пропадут при рестарте)
или задайте `DATABASE_URL=postgresql://…`. Если платформа не даёт HTTPS — `COOKIE_SECURE=false`.

## Чек-лист после публикации (ТЗ §5.5, §10.1)
- [ ] Ссылка открывается **с мобильного интернета без VPN** (и с другого провайдера / через check-host.net).
- [ ] `GET /api/health` → `{"status":"ok"}`.
- [ ] Вход `student1`, `student2`, `dekanat` работает; данные студентов различаются.
- [ ] Создать заявку → перезапустить приложение в панели хостинга → заявка на месте (том `/data` подключён).
- [ ] На телефоне (≥ 360 px) нет горизонтальной прокрутки, нижняя навигация работает.
- [ ] Хостинг оплачен/не уснёт до 28 ноября включительно (проверьте баланс и автоостановку).

## Обслуживание
- Сброс демо-данных: в консоли контейнера `python -m app.seed --reset` (или удалить `/data/deanate.db` и перезапустить).
- Бэкап: скопировать файл `/data/deanate.db`.
- Обновление каталога материалов: правка `backend/app/seed/data/learning_resources.json` + деплой — синхронизируется при старте.
