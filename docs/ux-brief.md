# UX-бриф для frontend

> **Изменение 22.11 (по замечанию заказчика):** деканат больше не выставляет баллы. Раздел `/staff/grades` называется «Успеваемость студентов» и работает только на просмотр: факультет → кафедра → группа → студент, с сообщением для групп без студентов. Описание ниже — исходный проект.

Компактная спецификация интерфейса «Цифровой деканат будущего»: дизайн-система, логотип, общие компоненты, затем по каждому экрану — блоки, обязательные состояния, тексты и мобильные особенности.
Структура экранов и маршруты — `information-architecture.md`; подача аналитики и тексты риска — `analytics-ux.md`; сценарии для самопроверки — `user-journeys.md`.

**Жёсткие правила**
1. Работаем от 360 px; горизонтальной прокрутки страницы нет ни на одном экране.
2. Любая цель касания ≥ 44 × 44 px, между соседними целями ≥ 8 px.
3. Цвет никогда не единственный носитель смысла: всегда текст + иконка.
4. Интерфейс не считает риск, пороги и цели — только показывает ответ API.
5. Нет кнопок «в никуда»: недоступное действие — `disabled` с пояснением рядом.
6. Плашка «Концепт для конкурса, не официальный сервис университета» — на каждой странице, включая вход и служебные экраны.
7. Все тексты — на русском, обращение на «вы».

## 1. Визуальное направление

### 1.1. Характер

«Спокойный навигатор»: собранный, светлый, тёплый. Много воздуха, крупные числа, чёткая иерархия «вывод → данные → детали». Никаких градиентов-радуг, декоративных иллюстраций и стоковых фото. Цвета риска появляются только там, где речь о риске; фирменный цвет — для действий и навигации. Скругления дружелюбные, но не «игрушечные».

### 1.3. Типографика

Шрифт — **Manrope** (лицензия SIL Open Font License 1.1, есть кириллица). Подключать локально (пакет `@fontsource/manrope` или файлы в репозитории), без внешнего CDN — так шрифт гарантированно грузится из России. Начертания: 400, 500, 600, 700, 800. Запасной стек: `"Manrope", system-ui, -apple-system, "Segoe UI", Roboto, Arial, sans-serif`.

| Стиль | Размер / межстрочный | Начертание | Где |
|---|---|---|---|
| Display | 44 / 48 (телефон 40 / 44) | 800 | Число индекса на радаре |
| H1 | 24 / 32 (десктоп 28 / 36) | 700 | Заголовок экрана |
| H2 | 20 / 28 | 700 | Заголовки блоков |
| H3 | 17 / 24 | 600 | Заголовки карточек, названия дисциплин |
| Body | 16 / 24 | 400 | Основной текст, поля ввода |
| Body-strong | 16 / 24 | 600 | Числа в тексте, важные значения |
| Small | 14 / 20 | 400–500 | Вторичный текст, подписи полей (600) |

- Числа баллов, время и даты — `font-variant-numeric: tabular-nums`, чтобы столбцы не «прыгали».
- Длина строки текста — не больше 70 знаков на десктопе.
- Заглавные буквы для акцента не используем.

### 1.4. Сетка, отступы, плотность

- База — 4 px. Шкала отступов: 4, 8, 12, 16, 20, 24, 32, 40, 48.
- Поля страницы: 16 px (телефон), 24 px (600–959), 32 px (≥ 960). Контент — до 1200 px.
- Карточки: внутренний отступ 16 px (телефон) / 20 px (десктоп); между карточками 12 / 16 px.
- Строки списков — минимум 56 px; строка с двумя строками текста — 72 px.
- Плотность «комфортная»: на экране одно основное действие; вторичные — текстовыми кнопками.
- Точки перестройки: 600, 960, 1280 px (`information-architecture.md`, раздел 9).

### 1.5. Скругления, поверхности, тени

| Элемент | Радиус |
|---|---|
| Поля ввода, мелкие элементы | 10 px |
| Кнопки | 12 px |
| Карточки, блоки | 16 px |
| Шторки (верхние углы), главная карточка индекса | 24 px |
| Чипы, бейджи, аватар, переключатели | полностью скруглённые |

Тени: карточки на `--bg` — `0 1px 2px rgba(21,26,45,.06)` + рамка `--border`; шторки, меню, тосты — `0 8px 24px rgba(21,26,45,.12)`.

### 1.6. Иконки и движение

- Иконки — **Lucide** (лицензия ISC): 24 px в навигации, 20 px в контенте, толщина линии 2. Названия в этом документе — ориентиры; при отсутствии в версии — ближайший аналог.
- Анимации 150–250 мс, `ease-out`: раскрытие аккордеона, шторки, появление тостов, движение маркера шкалы при загрузке. При `prefers-reduced-motion: reduce` — без анимаций и без мерцания скелетонов.
- Иллюстраций нет. Пустые состояния — иконка в круге 48 px на `--primary-tint`, заголовок, текст, действие.

## 2. Логотип

**Название в интерфейсе:** «Цифровой деканат»; полное — «Цифровой деканат будущего» (на странице входа и в «О прототипе»).

**Знак:** скруглённый квадрат цвета `--primary` (радиус ≈ 28 % стороны). Внутри — белый контур арки-проёма (две вертикальные стойки и полукруг сверху: «вход», универсальный образ двери деканата и аудитории). В нижней трети арки — белая точка, от неё вверх-вправо расходятся две концентрические дуги — «радар». Смысл: «вход в учебную жизнь, где всё видно заранее»; знак связан с главной функцией — Академическим радаром.

**Словесная часть:** Manrope 800, цвет `--text`, межбуквенный интервал −1 %. В левой панели под ней — Caption `--text-3`: «концепт для конкурса».

**Варианты:** знак + надпись (шапка десктопа, левая панель, вход); только знак (мобильная шапка, favicon 32 и 16 px — в 16 px остаётся арка и точка, без дуг); монохромный белый на `--primary` и `--primary` на белом.

**Нельзя:** герб, изображения зданий, аббревиатура или название вуза внутри знака, официальные цвета, шрифты и элементы фирменного стиля университета; знак не должен повторять официальный логотип ни формой, ни композицией (ТЗ §6.3). Логотип рисуется в SVG из простых фигур, без сторонних материалов.

## 3. Каркас и общие компоненты

### 3.1. Плашка-дисклеймер
- На каждой странице над шапкой, не липкая. Фон `--surface-2`, текст Caption `--text-2`, иконка `info` 16 px.
- Текст: «Концепт для конкурса, не официальный сервис университета» (от 600 px добавляется «· Данные вымышлены»). На 360 px допустим перенос на 2 строки.

### 3.2. Шапка (телефон, 56 px)
- Экраны первого уровня: знак + заголовок раздела слева; справа «?» (`circle-help`, aria-label «Помощь») и аватар с инициалами (aria-label «Профиль»). Обе кнопки 44 × 44.
- Вложенные экраны: «‹» (aria-label «Назад»), заголовок в 1 строку с многоточием (полное название — в H1 ниже), справа те же «?» и аватар.
- Формы: «‹» и заголовок; нижняя панель скрыта.

### 3.3. Нижняя панель (телефон и планшет)
- 5 пунктов: **Главная** (`house`), **Расписание** (`calendar-days`), **Учёба** (`graduation-cap`), **Заявки** (`file-text`), **Уведомления** (`bell`).
- Высота 64 px + `env(safe-area-inset-bottom)`; белый фон, верхняя рамка `--border`; каждый пункт — во всю ширину пятой части экрана (на 360 px — 72 px).
- Активный: иконка и подпись `--primary`, под иконкой капсула `--primary-tint`; неактивные — `--text-3`. `aria-current="page"`.
- Счётчик непрочитанных: бейдж `--primary`, белый Caption 600, «1»–«9», «9+». Для диктора: «Уведомления, 3 непрочитанных».
- Контенту — нижний отступ = высота панели + 16 px.

### 3.4. Левая панель (≥ 960 px)
- 248 px; сверху логотип; пункты высотой 44 px (иконка + подпись + счётчик); активный — фон `--primary-tint`, текст `--primary-hover`.
- Внизу: «Помощь», плашка «Концепт для конкурса, не официальный сервис университета · Данные вымышлены».
- Справа вверху контента — «?» и аватар с меню («Профиль», «Выйти»).

### 3.5. Кнопки
| Вид | Стиль | Когда |
|---|---|---|
| Основная | Фон `--primary`, белый текст 16/600 | Одно главное действие экрана |
| Вторичная | Белый фон, рамка `--border-strong`, текст `--text` | «Сохранить черновик», «Что если…», «Повторить» |
| Текстовая | Без фона, текст `--primary` | «Показать ещё», «Все заявки» |
| Деструктивная | Белый фон, рамка и текст `--critical-text` | «Отозвать заявку», «Удалить черновик» |

Высота 48 px (телефон), 44 px (десктоп). На телефоне главные действия форм — во всю ширину. Загрузка: спиннер слева + текст в форме процесса («Отправляем…»), кнопка неактивна. Неактивная: фон `--surface-2`, текст `--text-3`, рядом пояснение текстом (наведение на телефоне недоступно).

### 3.6. Поля ввода
- Подпись над полем (Small 600), обязательность — «*» и подпись «Обязательное поле» для диктора.
- Высота 48 px, шрифт 16 px (без автозума iOS), рамка `--border-strong`, фокус — кольцо 2 px `--primary` с отступом 2 px.
- Подсказка под полем (Small `--text-3`); ошибка — иконка `circle-alert` + текст `--critical-text`, рамка `--critical-solid`, связь через `aria-describedby`.
- Счётчик символов для текстов с лимитом: «120 / 500», при превышении — красным.
- Числа: `inputmode="numeric"`; выбор из списка — нативный `select` или собственная шторка с вариантами 48 px.
- Валидация — при уходе из поля и при отправке; при отправке над кнопкой сводка «Исправьте 2 поля» со ссылками-якорями, фокус на первое ошибочное поле.

### 3.7. Чипы
- Отображения (риск, статус, изменение): высота 28 px, иконка 16 px + текст Small 600, без интерактивности.
- Фильтры (зоны, категории уведомлений, статусы у сотрудника): высота 36 px визуально, область касания 44 px; выбранный — `--primary-tint` + рамка `--primary`; ряд чипов переносится на новые строки (а не прокручивается вбок).

### 3.8. Карточки и списки
- Кликабельная карточка — вся карточка ссылка, справа `chevron-right`; состояние нажатия — фон `--surface-2`.
- Строка дисциплины: полоса 4 px слева цвета уровня риска, чип риска, название (до 2 строк), «42 из 70 · Экзамен», мини-полоса баллов.
- Длинные названия в карточках переносятся полностью; в строках списка — максимум 2 строки с многоточием.

### 3.9. Шторки, диалоги, тосты, баннеры
- **Шторка**: снизу, скругление 24 px, ручка 36 × 4, заголовок + «Закрыть» (44 px), максимум 90 % высоты, прокрутка внутри; закрывается свайпом, крестиком, «Назад». На десктопе — правая панель 420 px.
- **Диалог подтверждения**: заголовок-вопрос, одно предложение последствий, кнопки. Телефон — кнопки друг под другом (действие сверху); десктоп — справа «Отмена», «Действие».
- **Тост**: над нижней панелью (телефон), слева снизу (десктоп); 4 с; кнопка «Закрыть»; `role="status"`.
- **Баннер в странице**: «Нужен ваш ответ» — tint «Требует внимания» + `message-circle-question`; «Нет соединения» — тёмный `--text` фон, белый текст, иконка `wifi-off`, липкий сверху.

## 4. Обязательные состояния (общий паттерн)

| Состояние | Как выглядит | Общий текст (уточняется по экранам ниже) |
|---|---|---|
| **Загрузка** | Скелетоны формы контента (не крутилка на весь экран); блоки грузятся независимо; кнопка — спиннер + «…ем» | — |
| **Пусто** | Иконка в круге + заголовок + 1–2 строки + действие (если есть) | Говорим, что здесь появится, и что можно сделать |
| **Ошибка сети / сервера** | В блоке: иконка `cloud-off`, текст, «Повторить»; остальные блоки работают | «Нет связи с сервером. Проверьте интернет и попробуйте ещё раз» / «Что-то пошло не так на нашей стороне. Попробуйте ещё раз через минуту» |
| **Ошибка валидации** | Под полем + сводка над кнопкой | Конкретно: что не так и как исправить |
| **Успех** | Тост или экран подтверждения (для отправки заявки) | «Черновик сохранён», «Ответ отправлен» |
| **Недоступно** | `disabled` + пояснение рядом | «Все работы оценены — моделировать нечего» |
| **Нет поиска** | Как «Пусто», с текстом запроса | «По запросу «…» ничего не нашлось» |

## 8. Чек-лист мобильной приёмки (360 px)

- [ ] Нет горизонтальной прокрутки страницы ни на одном экране (проверить с длинными названиями дисциплин и ФИО).
- [ ] Цели касания ≥ 44 × 44 px, промежутки ≥ 8 px; иконки-кнопки в шапке — 44 px.
- [ ] Шрифт полей ≥ 16 px; правильные `inputmode` и `autocomplete`.
- [ ] Нижняя панель не перекрывает контент, тосты и кнопки; учтён `safe-area-inset-bottom`.
- [ ] Формы: нижняя панель скрыта, кнопки в конце формы, клавиатура не закрывает поле в фокусе.
- [ ] Шторки и диалоги закрываются «Назад»; прокрутка под шторкой заблокирована.
- [ ] Таблицы (зачётная книжка, очередь сотрудника) превращены в строки-карточки.
- [ ] Ряды чипов переносятся, а не уходят вбок.
- [ ] Шкала индекса и полосы баллов читаемы, подписи не накладываются.
- [ ] Горизонтальная ориентация не ломает раскладку.
- [ ] На 360 × 740 первый экран Главной: приветствие, «Сегодня», начало карточки индекса.

## 9. Доступность

- `lang="ru"`; ориентиры `header`, `nav`, `main`; ссылка «Перейти к содержимому» в начале страницы.
- Иерархия заголовков без пропусков: одна H1 на экран.
- Видимый фокус (кольцо 2 px `--primary`) у всех интерактивных элементов; порядок табуляции — визуальный.
- Шкала индекса и полосы баллов — `role="img"` с текстовым `aria-label`; числа дублируются текстом рядом.
- Динамические изменения (тосты, результат «Что если», ошибки формы) — через `aria-live="polite"` (ошибки отправки — `role="alert"`).
- Контраст по таблицам раздела 1.2; при увеличении до 200 % контент не обрезается.
- Цвет не единственный носитель информации (риск, статусы, изменения, непрочитанное — всегда с текстом/иконкой).
- `prefers-reduced-motion` — без анимаций.
- Внешние ссылки — с пометкой «откроется в новой вкладке» для диктора.
