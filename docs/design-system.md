# Дизайн-система «Цифровой деканат»

Собственная лёгкая дизайн-система без UI-китов и CDN: CSS-переменные (`frontend/src/styles/tokens.css`),
базовые стили (`base.css`), компоненты (`components.css` + `src/components/ui/*`), каркас (`layout.css`), стили экранов (`pages.css`).

## Характер
Спокойный современный интерфейс для ежедневного использования: светлый фон, белые карточки с мягкой тенью,
скругления 8–20 px, один насыщенный акцент (индиго `#3b44d1`), крупные цифры для баллов. Цвет зон риска — отдельная
семантическая палитра, которая не используется для декора.

## Токены
| Группа | Значения |
|---|---|
| Фон / поверхность / текст | `--c-bg #f5f6fa`, `--c-surface #fff`, `--c-text #151a2d` (контраст 17,3:1) |
| Акцент | `--c-accent #3b44d1` (белый текст 7,2:1), hover/active темнее, `--c-accent-soft` для фонов |
| Зоны риска (линия · текст · фон · рамка) | critical `#d92d20` · high `#e35d0f` · medium `#eaaa08` · low `#15a397` · stable `#17b26a` · нет данных `#808a9c`; для каждой есть `-text` (контраст ≥ 4,5:1 на светлом фоне), `-soft`, `-border` |
| Типографика | Manrope 400/500/600/700 (self-hosted через `@fontsource/manrope`, latin + cyrillic); шкала 12/14/16/18/20/24/30/40 px; цифры — `font-variant-numeric: tabular-nums` (класс `.num`) |
| Отступы | шкала 4 px: 4, 8, 12, 16, 20, 24, 32, 40, 48 |
| Радиусы | 6, 8, 12, 16, 20 px и pill |
| Каркас | нижняя панель на мобильных (5 пунктов), левая панель 248 px от 960 px |

## Компоненты (`src/components/ui`)
Button / ButtonLink / IconButton (варианты primary · secondary · ghost · danger; loading и disabled; зона касания ≥ 44 px) ·
Card / CardHeader · Badge, **RiskBadge** (цвет + иконка + текст), ZoneBadge, StatusPill (статусы заявок), TargetBadge ·
Segmented (переключатель или вкладки с навигацией стрелками) · TextField / TextAreaField / SelectField (label, подсказка,
ошибка, счётчик, `aria-invalid`, `aria-describedby`) · Callout · EmptyState / ErrorState (с «Повторить») / NoResults ·
Skeleton / SkeletonCard / PageSkeleton · Toast (success/error, `role="status"`) · Modal (на мобильных — bottom sheet) ·
**Gauge** (SVG-полукруг индекса) и IndexScale (шкала с зонами) · **PointsBar** (набрано · ещё можно набрать (штриховка) ·
нет данных (серая штриховка) + отметки порогов) · Avatar · PageHeader · Logo.

Доменные компоненты (`src/components/domain`): LessonCard (занятие с метками изменений), DisciplineRow, ZoneChips
(фильтр по зонам), ApplicationRow, NotificationRow, ApplicationForm (динамическая форма по описанию типа заявки).

## Правила
- **Цвет никогда не единственный носитель смысла:** риск, статус заявки, изменение расписания, непрочитанное уведомление
  всегда дублируются иконкой и текстом.
- Mobile-first: всё работает от 360 px; таблицы на узких экранах превращаются в карточки (`.table--responsive`);
  горизонтальная прокрутка страницы запрещена (проверяется в `frontend/e2e/smoke.py`).
- У каждого экрана есть состояния загрузки (скелетоны), пустое, ошибка с повтором; у форм — ошибки по полям (клиент + сервер)
  и блокировка кнопки на время отправки.
- Доступность: семантические заголовки, `label` у полей, видимый фокус (`:focus-visible`), подписи у кнопок-иконок,
  `prefers-reduced-motion` отключает анимации, внешние ссылки — с пометкой «откроется в новой вкладке».
- Дисклеймер «Концепт для конкурса, не официальный сервис университета» — в шапке каждой страницы и на экране входа.
- Логотип — собственный SVG-знак (стилизованный «радар» в скруглённом квадрате), не воспроизводит символику вуза.
