## Задача
Собери каталог проверенных открытых учебных материалов и сохрани его в `backend/app/seed/data/learning_resources.json`:

```jsonc
{
  "_meta": {"checked_on": "YYYY-MM-DD", "method": "кратко: как искали и проверяли"},
  "resources": [
    {
      "id": "r001",
      "topic_keys": ["dm-shortest-paths"],             // одна или несколько тем из curriculum.json
      "title": "Точное название страницы/курса/видео",
      "type": "article",                              // article | video | lecture | textbook | notes | course | practice | documentation
      "source": "Название сайта/платформы/издателя",
      "author": "Автор или организация, если явно указаны на странице, иначе null",
      "url": "https://...",
      "language": "ru",                               // ru | en
      "summary": "1–2 предложения СВОИМИ словами: что внутри",
      "relevance": {"dm-shortest-paths": "почему это поможет именно по этой теме"},
      "difficulty": "basic",                          // basic | intermediate | advanced | null — только если можно обосновать
      "duration_minutes": null,                       // только если указано на странице или очевидно (длительность видео)
      "link_status": "verified",                      // verified — WebFetch открыл страницу и содержание соответствует теме; unverified — не удалось проверить
      "checked_on": "YYYY-MM-DD",
      "access_note": "Открытый доступ" // или особенности: регистрация, англ. язык и т.п.
    }
  ],
  "topics_without_materials": [{"topic_key": "...", "note": "честно: почему не нашлось подходящего"}]
}
```

### Требования к подбору (обязательные)
1. Каждый URL открой через WebFetch и убедись, что страница существует и действительно про эту тему. Только тогда `verified`. Неподтверждённое либо не включай, либо ставь `unverified` с пояснением в `access_note` (лучше не включать).
2. Не выдумывай названия, авторов, ссылки, длительность и содержание. Автор — только если он виден на странице.
3. Только легальные открытые источники: никаких пиратских копий книг, «скачать бесплатно pdf» с файлообменников. Предпочитай: Википедия, Викиконспекты ИТМО (neerc.ifmo.ru/wiki), открытые курсы (Stepik, Открытое образование, Лекториум, ИНТУИТ), официальная документация (cppreference и т.п.), университетские открытые конспекты, MIT OpenCourseWare, Khan Academy, учебные порталы. Сайты должны открываться из России без VPN — по возможности избегай сервисов, которые в РФ заблокированы или сильно замедлены (видео на YouTube — только если нет альтернативы; отметь это в `access_note`).
4. Предпочитай русскоязычные материалы; англоязычные допустимы (для тем по английскому — естественно), язык указывай.
5. Краткое содержание пиши своими словами, без копирования абзацев (цитаты не нужны вовсе).
6. 1–3 материала на тему; цель — хотя бы один проверенный материал для ≥ 85% тем и два — для ≥ половины. Начни с тем дисциплин: control-theory, probability, mcu, tmm, economics, discrete-math, physics-em (они в зоне риска у демо-студентов), затем остальные.
7. Если для темы не нашлось качественного проверенного материала — добавь её в `topics_without_materials` с честным пояснением. Пустая подборка лучше фиктивной.
8. Все `topic_keys` должны существовать в curriculum.json; `id` уникальны; JSON валиден (проверь: `python3 -I -c "import json;json.load(open('backend/app/seed/data/learning_resources.json'))"`).

Также создай `docs/learning-resources.md`: источники тем (учебный план прототипа), критерии отбора, процесс поиска и проверки ссылок, статистика (тем всего / с материалами / без), перечень использованных платформ и условия доступа, как архитектура позволяет позже подключить поиск по открытым источникам или RAG по материалам курса (кратко, 3–5 пунктов).
