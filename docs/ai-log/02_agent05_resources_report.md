# Отчёт агента 05 (учебные материалы) — получен 22.11.2026

Работа шла в два захода: первый прервался по лимиту API после сборки каталога, второй (после возобновления координатором)
завершил документ `docs/learning-resources.md` без перезаписи готового каталога.

**Статистика:** 142 материала (115 на русском, 27 на английском); материалы есть у 63/63 тем, ≥ 2 материала — у 63/63, три — у 28;
10 материалов привязаны к нескольким темам; автор указан у 82 (только если виден на странице); `duration_minutes` — лишь там,
где время указано на странице (3 материала). Все записи `verified`: каждый URL открыт через WebFetch и сверен с темой.

**Источники:** mathprofi.ru (25), Википедия (22), открытые PDF вузов (23: ТПУ, библиотека МГТУ им. Баумана, ВлГУ, ТУСУР, ЮУрГУ,
СПбПУ, МГУ, ВГТУ, БГУИР и др.), METANIT (12), Хабр (10), OpenStax (9), AlexGyver (8), Викиконспекты ИТМО (8), Stepik, cppreference,
LibreTexts, All About Circuits, БРЭ. YouTube не использовался (замедлен в РФ).

**Слабые места (честно отмечены в `relevance`):** `en3-vocab` — только англоязычные глоссарии; `mcu-architecture` — Cortex-M раскрыт слабо;
`eg-dimensions` — одно пособие по ГОСТ 2.307-68 (действует 2.307-2011); `calc-surface-integrals` — основа в вузовских пособиях.

**Отсеяно при проверке:** ~10 статей Википедии, не открывшихся инструментом; нестабильные страницы neerc/e-maxx; платный курс Stepik;
материалы с неясной лицензией (коммерческие учебники на сторонних сайтах); сайты за защитой от ботов.
Доступность из российской сети агент проверить не мог — оговорено в документе.
