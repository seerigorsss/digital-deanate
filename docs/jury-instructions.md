# Инструкция для жюри

**Ссылка на прототип:** `<будет указана после публикации>`
Работает в браузере на телефоне и компьютере, установка не требуется. Это концепт для конкурса, а не официальный сервис; все данные вымышлены.

## Что проверить за 5 минут
1. **Вход и профиль.** Войдите как `student1` → аватар в шапке → «Профиль». Выйдите, войдите как `student2` — другие ФИО, факультет, курс, группа, расписание и оценки.
2. **Главная.** Занятия на сегодня (или ближайшее занятие), индекс учебной устойчивости, ближайшие сроки, заявки, уведомления.
3. **Расписание.** Переключите «День / Неделя» и листайте недели: отмены, переносы, замены аудитории и преподавателя выделены цветом и подписью
   (больше всего изменений — на неделе 23–29 ноября).
4. **Учёба → Академический радар.** У `student2`: индекс с пометкой «ориентировочный», распределение по зонам,
   «Что подтянуть в первую очередь». Откройте «Теория механизмов и машин» (критический риск — причина показана числами),
   затем дисциплину с экзаменом (например, «Теория автоматического управления»): семестр + экзамен, обязательные 18 баллов,
   достижимость 60/71/85. Внизу — «Что если»: введите баллы за будущие работы и нажмите «Пересчитать».
   Откройте тему, отмеченную «стоит повторить», — подборка проверенных материалов.
5. **Заявки.** «Новая заявка» → «Справка об обучении» → заполните → «Отправить» → заявка в списке со статусом
   «Отправлена». Обновите страницу — заявка сохранилась. У `student2` есть заявка «Требуется уточнение» — ответьте
   в переписке, статус вернётся в «Отправлена».
6. **Деканат.** Войдите как `dekanat` → откройте вашу заявку → смените статус (например, «В обработке» → «Готова к получению»).
   Войдите снова студентом — новый статус и уведомление. В разделе «Студенты и баллы» выставьте балл — аналитика студента пересчитается.
7. **Изоляция данных.** Под `student1` откройте заявку и запомните число в адресе (`/applications/<id>`).
   Войдите как `student2` и откройте тот же адрес — «Заявка не найдена». Прямой запрос к API
   `GET /api/applications/<id>` из второго аккаунта тоже вернёт 404.
8. **Телефон.** Все сценарии работают на экране от 360 px: нижняя панель навигации, формы и карточки без горизонтальной прокрутки.
