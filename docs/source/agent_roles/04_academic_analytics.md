# Роль: разработчик алгоритма академической аналитики

Реализуй детерминированный, объяснимый и тестируемый алгоритм. Правила бери из основного ТЗ.

Типы аттестации:
1. Зачёт: минимум 60 семестровых баллов.
2. Распределённый экзамен: 0–100 набираются в семестре.
3. Экзамен с отдельной частью: до 70 семестровых баллов + 18–30 экзаменационных; экзаменационный минимум — 18.

Шкала: 0–59 неудовлетворительно, 60–70 удовлетворительно, 71–84 хорошо, 85–100 отлично. Неоднозначность исходной границы 60 должна быть явно задокументирована и вынесена в конфигурацию.

Разделяй текущие баллы, максимум завершённых модулей, оставшийся потенциал, прогнозируемый результат и риск недостижения порога. Низкий балл в начале семестра не означает автоматически критический риск.

Уровни: critical, high, medium, low, stable, insufficient_data. Критический — порог математически недостижим или обязательное условие невозможно выполнить; высокий — требуется почти весь остаток/резкий рост темпа; средний — достижимо с небольшим запасом; низкий — достижимо реалистично; stable — есть достаточный запас; insufficient_data — недостаточно данных. Не выдавай эвристику за статистическую вероятность.

Расчёты:
- Зачёт: сравни сумму с 60, вычисли дефицит и проверь оставшийся максимум.
- Распределённый экзамен: проверь достижимость 60, 71, 85 с учётом будущих модулей.
- Экзамен: итог = семестровые + экзаменационные. Для цели T вычисли T минус семестровые баллы; если нужно менее 18, всё равно требуется 18; если более 30, цель недостижима без дополнительных семестровых баллов. Показывай итог при экзамене на 18 и на 30. Результат экзамена ниже 18 не считается сдачей.

Согласуй структуру ответа с backend и frontend: текущие баллы, максимумы, остаток, пороги, достижимость целей, риск, причины, рекомендации, полнота данных и человекочитаемое объяснение.

Сводный индекс должен иметь прозрачную формулу, не скрывать один критический предмет за несколькими зелёными, показывать число предметов в каждой зоне и называться ориентировочным индексом, а не вероятностью сдачи.

Покрой тестами 59/60, 60/71/85, минимум 18, максимум 30, недостижимые цели, нулевой остаток, ранний/поздний семестр, недостаток данных, одну критическую дисциплину и пересчёт после изменения баллов.

Запрещено генерировать случайные баллы, считать риск только по текущему проценту и игнорировать обязательный экзаменационный минимум.
