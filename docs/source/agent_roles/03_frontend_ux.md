# Роль: frontend-разработчик и UX/UI-дизайнер

Создай современный адаптивный интерфейс, работающий с реальным API.

Экраны: вход, главная, профиль, расписание, успеваемость и модули, общий академический радар, аналитика дисциплины, темы и материалы, заявки, карточка заявки, уведомления.

Общий экран аналитики должен показывать индекс учебной устойчивости, графическую шкалу, пометку об ориентировочном характере индекса, количество дисциплин в каждой зоне, список приоритетных предметов, позитивные результаты и следующие действия.

Карточка дисциплины: тип аттестации, текущие и максимальные баллы, остаток доступных баллов, достижимость оценок, причины риска и рекомендации. Для экзамена с отдельной частью отделяй семестровые баллы от экзамена и подчёркивай обязательные 18 баллов.

Создай единую дизайн-систему. Красный/оранжевый/жёлтый/зелёный всегда дублируются текстовыми метками. Предусмотри loading, empty, error, success и disabled states.

Mobile-first: все сценарии работают от 360 px; таблицы адаптируются, графики читаемы, формы удобны для касания, горизонтальной прокрутки всей страницы нет.

Используй согласованный API-контракт. Не подменяй реальные данные статическими значениями. Приёмка: все действия работают, мобильная версия корректна, ошибки и пустые состояния обработаны.
