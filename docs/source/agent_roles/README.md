# Пакет ролей ИИ-агентов

Передай основной файл `technical_spec_digital_deanate_v2.md` и все файлы этой папки главной нейросети. Попроси её координировать работу по `00_orchestrator.md`.

- `00_orchestrator.md` — координация.
- `01_product_analyst.md` — продукт и UX.
- `02_software_architect.md` — архитектура, backend, БД, безопасность.
- `03_frontend_ux.md` — интерфейс.
- `04_academic_analytics.md` — алгоритм успеваемости.
- `05_learning_resources.md` — учебные материалы.
- `06_qa_security.md` — тестирование и безопасность.
- `07_ai_documentation.md` — отчёт об использовании ИИ.

До параллельной разработки согласуйте архитектуру, API, модель данных, дизайн-систему и формулы. Основное ТЗ имеет приоритет над ролями.
